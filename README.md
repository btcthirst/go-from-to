# Excel Parser - Обробка Даних Нарахувань та Виписок

Програма з графічним інтерфейсом (GUI) для обробки документів нарахувань та банківських виписок з автоматичною заміною особистих рахунків на ПІБ (повні імена та прізвища).

## Функціональність

- **Графічний інтерфейс (Fyne)**: інтуїтивний GUI для вибору файлів та перегляду результатів
- **Читання файлів нарахування** (ODS/XLSX): витягує ПІБ та особисті рахунки мешканців
- **Читання файлів виписки** (XLSX): витягує дані платежів (дату, суму, контрагента)
- **Пошук та заміна**: шукає рахунки контрагентів у списку нарахувань та замінює їх на ПІБ
- **Експорт результатів**: зберігає результати в ODS файл
- **Динамічна конфігурація**: підтримка різних форматів документів без перекомпіляції
- **Оптимізовані алгоритми**: швидка обробка великих файлів

## Встановлення та Запуск

### Вимоги
- Go 1.22 або новіше
- Операційна система: Linux, macOS, Windows

### Побудова
```bash
make build
```

### Запуск з GUI
```bash
make run
```

Програма запустить графічний інтерфейс, де ви зможете:
1. Вибрати файл нарахувань (ODS або XLSX)
2. Вибрати файл виписки (XLSX)
3. Переглянути завантажені дані у таблицях
4. Зберегти результати обробки в ODS файл

### Очистка
```bash
make clean
```

## Роботи з GUI

### Основний екран

1. **Вибір файлів**
   - Натисніть "Вибрати файл нарахувань" для завантаження ODS/XLSX файлу
   - Натисніть "Вибрати файл виписок" для завантаження XLSX файлу

2. **Таблиці результатів**
   - **Нарахування**: Показує завантажені дані про мешканців (ПІБ, Рахунок)
   - **Платежі**: Показує знайдені платежі зі заміною рахунків на ПІБ
   - **Відрахування**: Показує знайдені відрахування (платежі з негативною сумою)

3. **Збереження результатів**
   - Натисніть "Зберегти як..." для збереження результатів у файл

## Конфігурація

Програма використовує файл `config/document_config.yaml` для визначення структури документів:

```yaml
documents:
  accruals:
    data_start_row: 7           # Рядок, з якого починаються дані
    header_end_row: 6          # Останній рядок заголовка
    columns:
      full_name:
        index: 1               # Індекс колонки з ПІБ (0-indexed)
      account:
        index: 2               # Індекс колонки з рахунком
    min_columns: 3
    required_columns:
      - full_name
      - account
```

**Для налаштування нових форматів документів:**
1. Відкрийте `config/document_config.yaml`
2. Змініть індекси колонок та номери рядків закладок за вашими потребами
3. Перезапустіть програму

Детальніше див. [CONFIG_GUIDE.md](docs/CONFIG_GUIDE.md).

## Формати Файлів

### Вхідні Файли

#### Файл Нарахувань
Формати: ODS або XLSX

Структура (за замовчуванням):
- **Рядки 1-6**: Заголовок та метаінформація
- **Рядок 7+**: Дані мешканців
  - Колонка 2 (індекс 1): ПІБ (повне ім'я мешканця)
  - Колонка 3 (індекс 2): Особистий рахунок

#### Файл Виписки (Банківська Виписка)
Формат: XLSX

Структура (за замовчуванням):
- Містить слово "Дата" у першій колонці рядка з заголовками
- Рядок після заголовка: дані платежів
  - Колонка 2 (індекс 1): Дата проводки
  - Колонка 4 (індекс 3): Сума платежу
  - Колонка 6 (індекс 5): Призначення платежу
  - Колонка 8 (індекс 7): Назва контрагента
  - Колонка 9 (індекс 8): Рахунок контрагента

### Вихідний Файл

#### `summery.ods`
Таблиця з колонками (за замовчуванням):
- **Дата**: Дата платежу
- **Сума**: Сума платежу (позитивна для платежів, негативна для відрахувань)
- **ПІБ**: ПІБ мешканця (якщо знайдено за рахунком)
- **Рахунок**: Особистий рахунок контрагента
- **Контрагент**: Назва контрагента або ПІБ мешканця
- **Призначення**: Призначення платежу
- **Тип**: "Платіж" або "Відрахування"

## Логіка Обробки

1. **Завантаження нарахувань**: програма читає файл нарахування та створює карту `рахунок → ПІБ`
2. **Завантаження платежів**: читає файл виписки та отримує дані платежів
3. **Оптимізована обробка**: використовує карту для швидкого пошуку рахунків (O(1) замість O(n))
4. **Заміна назв**: якщо рахунок знайдено, замінює назву контрагента на ПІБ мешканця
5. **Класифікація**: розділяє результати на платежи та відрахування (за знаком суми)
6. **Експорт**: записує результати у вихідний ODS файл

## Оптимізація Продуктивності

Програма оптимізована для роботи з великими файлами:

- **Швидкий пошук рахунків**: використовує hash map O(1) замість лінійного пошуку O(n)
- **Потокова обробка**: завантаження файлів виконується в окремих горутинах для відзивчивого GUI
- **Динамічна конфігурація**: не потребує перекомпіляції при зміні структури документів

## Вирішення Проблем

### "Помилка при читанні нарахувань"
- Переконайтеся, що файл має коректну структуру за конфігурацією
- Використовуйте `cmd/debug/main.go` для аналізу структури файлу
- Оновіть `config/document_config.yaml` відповідно до вашого формату

### Результати не показуються
- Переконайтеся, що обидва файли (нарахування та виписка) вибрані
- Перевірте, чи відповідають індекси колонок у конфігурації вашим файлам

### ODS файли не читаються
- Переконайтеся, що файл є коректним ZIP архівом ODS формату
- Спробуйте конвертувати файл у XLSX та спробуйте знову

### Програма працює повільно
- Роздробіть великі файли на менші частини
- Перевірте, чи вказано коректне число реків `data_start_row` у конфігурації
