# Excel Parser - Обробка Даних Нарахувань та Виписок

Програма для обробки документів нарахувань та банківських виписок з попиту та логіки заміни особистих рахунків на ПІБ (повні імена та прізвища).

## Функціональність

- **Читання файлу нарахування** (`нарахування26.xlsx`): витягує ПІБ та особисті рахунки мешканців
- **Читання файлу виписки** (`stmts_*.xlsx`): витягує дані платежів (дату, суму, контрагента)
- **Пошук та заміна**: шукає рахунки контрагентів у списку нарахувань та замінює їх на ПІБ
- **Генерація звіту**: зберігає результати в `summery.xlsx`

## Формат Файлів

### Вхідні Файли

#### `нарахування26.xlsx`
- **Рядок 6**: заголовки (№ кв, ПІБ, Особ. рах., і т.д.)
- **Рядок 7+**: дані про мешканців
  - Колонка 1: ПІБ (повне ім'я мешканця)
  - Колонка 2: Особистий рахунок (1001, 1002, і т.д.)

#### `stmts_*.xlsx` (Виписка банку)
- **Рядок 14**: заголовки таблиці платежів
- **Рядок 15+**: дані платежів
  - Колонка 1: Дата проводки
  - Колонка 3: Сума
  - Колонка 5: Призначення платежу
  - Колонка 7: Назва контрагента
  - Колонка 8: Рахунок контрагента

### Вихідний Файл

#### `summery.xlsx`
Таблиця з колонками:
- **№**: Номер запису
- **Дата**: Дата платежу
- **Сума**: Сума платежу
- **ПІБ**: ПІБ мешканця (якщо знайдено)
- **Рахунок**: Особистий рахунок
- **Контрагент**: ПІБ контрагента (замінено на ім'я мешканця)

## Логіка Обробки

1. Програма читає файл нарахування та створює карту `рахунок → ПІБ`
2. Читає файл виписки та отримує дані платежів
3. Для кожного платежу шукає рахунок контрагента у вихідних рахунках
4. Якщо рахунок знайдено, замінює назву контрагента на ПІБ
5. Записує результати в `summery.xlsx`
