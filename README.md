# Bank Analyzer

Десктопний застосунок для імпорту, аналізу та категоризації банківських виписок (ПриватБанк), з можливістю генерації зручних бухгалтерських звітів (наприклад, «Журнал-ордер 311»). Написаний на Go з використанням графічного фреймворку [Fyne](https://fyne.io/).

![Screenshot](screenshot.png) *(тут можна додати скріншот екрану імпорту або таблиці транзакцій)*

## Основні функції

- **Імпорт виписок:** Підтримка форматів `.csv` та `.xlsx` з вивантажень ПриватБанку.
- **Автоматична категоризація:** Транзакції отримують категорії (Зарплата, Комунальні, Податки тощо) на основі налаштованих ключових слів.
- **Гнучка конфігурація:** Усі категорії, мапінг стовпців, ключові слова й постачальники задаються в YAML-файлах. 
- **Ручне редагування:** Зміна категорії і прив'язка до контрагента (наприклад, для внесків) просто з таблиці.
- **Генерація звітів:** Створення зведених фінансових звітів у форматах `.xlsx` або `.ods`, включно зі спеціалізованим «Журналом-ордером 311».

## Архітектура та стек

- **Мова:** Go 1.25
- **UI Фреймворк:** `fyne.io/fyne/v2`
- **Робота з XLSX:** `github.com/xuri/excelize/v2`
- **Робота з парсингом:** `gopkg.in/yaml.v3`, `github.com/shopspring/decimal`

Код розділено на ізольовані шари (CLI/UI, parsers, models, categorizer, reports), які спілкуються через інтерфейси (`parsers.Registry`, pub/sub у `AppState`).

## Встановлення та запуск

### Попередні вимоги
Оскільки додаток використовує Fyne, для збірки потрібні C-компілятори та драйвери екрану.

- **Linux:** `sudo apt install gcc libgl1-mesa-dev xorg-dev`
- **macOS:** Потрібен встановлений Xcode CL Tools (`xcode-select --install`)
- **Windows:** Встановлений MinGW-w64 або TDM-GCC.

### Збірка та запуск

Клонуйте репозиторій та зіберіть програму:

```bash
git clone https://github.com/yourusername/go-from-to.git
cd go-from-to
go mod tidy
go build -o bank-analyzer cmd/main.go
./bank-analyzer
```

## Налаштування (Конфігурація)

Правила категоризації та парсингу визначаються у YAML-файлах в директорії `assets/`. Якщо файли не знайдені, програма використає базові налаштування (embedded assets). 

**Основні файли конфігурації:**
1. `assets/categories.yaml` — створює категории і мапить їх на ключові слова.
2. `assets/column_mappings.yaml` — описує, як програма повинна мапити колонки таблиці (з CSV чи XLSX) до внутрішньої структури (Дата, Сума, Опис тощо).
3. `assets/report_311.yaml` — структура бухгалтерського "Журналу-ордеру 311".
4. `assets/providers.yaml` (опціональний) — мапінг кодів контрагентів до їхніх фактичних імен або рахунків для автопідстановки на екрані "Внески".

## Використання

1. **Імпорт файлів:** Перетягніть (Drag & Drop) `.csv` чи `.xlsx` виписки банку в вікно, або виберіть через кнопку "Додати файл". Парсинг відбувається паралельно у фоні.
2. **Перегляд транзакцій:** У однойменній вкладці можна переглядати усі дані. Клікніть по рядку, щоб змінити його категорію власноруч.
3. **Категорії:** Керуйте словником через інтерфейс. Будь-які зміни в ключових словах автоматично перерахують категорії всіх завантажених транзакцій.
4. **Звіт:** У вкладці "Звіти" оберіть потрібний період і шаблон. Згенеруйте фінальну таблицю.
