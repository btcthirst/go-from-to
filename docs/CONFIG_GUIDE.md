# Конфігурація документів

Цей файл описує, як налагодити обробку різних форматів документів (Excel/ODS) без необхідності перекомпіляції коду.

## Структура конфігурації

Конфіг знаходиться у `config/document_config.yaml` та визначає:

### Для файлу нарахувань (accruals)
- **data_start_row**: Номер рядка (1-indexed), з якого починаються дані (за замовчуванням: 7)
- **header_end_row**: Номер рядка (1-indexed), на якому закінчується заголовок (за замовчуванням: 6)
- **columns**: Визначення колонок та їх індексів (0-indexed):
  - `full_name`: Індекс колонки з ПІБ
  - `account`: Індекс колонки з номером рахунку
- **min_columns**: Мінімальна кількість колонок у рядку
- **required_columns**: Колонки, які обов'язково повинні мати значення

### Для файлу платежів (payments)
- **header_trigger**: Текст, який вказує на заголовок таблиці (за замовчуванням: "Дата")
- **columns**: Індекси колонок для:
  - `date`: Дата проводки
  - `amount`: Сума платежу
  - `purpose`: Призначення платежу
  - `counterparty_name`: Назва контрагента
  - `counterparty_account`: Рахунок контрагента
- **min_columns**: Мінімальна кількість колонок
- **required_columns**: Обов'язкові колонки

## Приклад налаштування для нових форматів

Якщо ваш файл нарахувань має іншу структуру, просто оновіть `config/document_config.yaml`:

```yaml
documents:
  accruals:
    name: "Файл нарахувань"
    data_start_row: 5      # Змініть на номер вашого рядка з даними
    header_end_row: 4      # Змініть на останній рядок заголовка
    columns:
      full_name:
        index: 0           # Індекс колонки з ПІБ
        name: "ПІБ особи"
      account:
        index: 3           # Індекс колонки з рахунком
        name: "Рахунок"
```

## Як дізнатися індекси колонок?

Використовуйте `cmd/debug/main.go` для аналізу структури файлу:

```bash
go run cmd/debug/main.go
```

Це виведе перші 15 рядків файлу з індексами всіх колонок.

## Завантаження конфігурації

Конфігурація автоматично завантажується при запуску програми:

```go
import "excel-parser/internal/config"

// На початку main()
if err := config.Load("config/document_config.yaml"); err != nil {
    log.Fatalf("Помилка завантаження конфігурації: %v\n", err)
}
```

## Відладка

Для перевірки, чи коректно завантажена конфігурація, використовуйте:

```go
accrualConfig, _ := config.GetDocumentConfig("accruals")
fmt.Printf("Дані починаються з рядка: %d\n", accrualConfig.DataStartRow)
fmt.Printf("Індекс колонки ПІБ: %d\n", accrualConfig.Columns["full_name"].Index)
```
