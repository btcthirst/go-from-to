# UI (Fyne) - Додано 

## Опис

До проекту додана графічна інтерфейс на основі Fyne, яка дозволяє:

1. **Вибір файлу нарахувань** - діалог для вибору ODS файлу з даними про нарахування
2. **Вибір файлу виписок** - діалог для вибору XLSX файлу з даними про платежі  
3. **Вибір місця для результатів** - діалог для вибору де зберегти результат обробки
4. **Обробка файлів** - кнопка для запуску обробки з вибраними файлами
5. **Статус операції** - відображення статусу обробки

## Зміни в проекті

### 1. **go.mod** 
- Додана залежність: `fyne.io/fyne/v2 v2.5.0`

### 2. **internal/ui/ui.go** (новий файл)
- Новий пакет `ui` з класом `UIManager`
- `NewUIManager()` - конструктор UI менеджера
- `Run()` - запускає GUI застосунок з Fyne

### 3. **internal/app/app.go**
- Рефакторинг функції `Init()` для збереження можливості запуску з командним рядком
- Нова функція `ProcessFiles(accrualFile, paymentFile, outputFile string)` - обробляє файли з передачею шляхів

### 4. **internal/excel/writer/writer.go**
- Оновлена функція `WriteResults(results []model.ResultRecord, outputFile string)` 
- Тепер приймає параметр `outputFile` для гнучкості при виборі місця збереження

### 5. **cmd/app/main.go**
- Оновлено для використання нового UI
- Замість прямого виклику `app.Init()` тепер запускається UI

## Використання

### Запуск програми з UI:
```bash
go run ./cmd/app/main.go
```

### Збірка:
```bash
go build -o bin/app ./cmd/app/main.go
```

## UI Функціональність

### Вікно програми містить:

1. **Заголовок** - "Обробник Excel/ODS файлів"

2. **Три кнопки для вибору файлів:**
   - "Вибрати файл нарахувань (ODS)"
   - "Вибрати файл виписок (XLSX)"  
   - "Вибрати місце для результатів"

3. **Інформаційне поле** - показує назви вибраних файлів

4. **Кнопка "Обробити файли"** - запускає обробку (активна тільки при виборі всіх файлів)

5. **Статус** - показує хід обробки

## Процес використання

1. Запустити програму
2. Натиснути "Вибрати файл нарахувань" та обрати ODS файл
3. Натиснути "Вибрати файл виписок" та обрати XLSX файл
4. Натиснути "Вибрати місце для результатів" та обрати/вказати де зберегти результат
5. Натиснути "Обробити файли"
6. Дочекатися повідомлення про успіх

## Залежності

- `fyne.io/fyne/v2 v2.5.0` - графічна бібліотека для Go
- Інші залежності залишення без змін

## Примітки

- UI запускається в окремому потоці для забезпечення чутливості інтерфейсу
- Всі діалоги є стандартними файловими діалогами операційної системи
- Обробка файлів відбувається асинхронно
