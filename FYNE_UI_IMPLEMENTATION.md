# Додано Fyne UI з діалогами вибору файлів

## Резюме змін

Успішно додана графічна інтерфейс (GUI) на основі фреймворку **Fyne** для проекту. UI дозволяє користувачам вибирати файли для обробки та місце для збереження результатів через стандартні діалоги операційної системи.

## Основні компоненти UI:

### 1. **Вибір файлу нарахувань (ODS)**
   - Діалог для вибору вихідного ODS файлу з даними про нарахування
   - Фільтр на розширення *.ods

### 2. **Вибір файлу виписок (XLSX)**
   - Діалог для вибору вихідного XLSX файлу з даними про платежі  
   - Фільтр на розширення *.xlsx

### 3. **Вибір місця для збереження результату**
   - Діалог для вибору місцезнаходження зберігання результату
   - Можливість вказати ім'я файлу результату (за замовчуванням summery.xlsx)
   - Фільтр на розширення *.xlsx

### 4. **Кнопка обробки**
   - Активна тільки коли всі три файли вибрані
   - Запускає обробку в окремому потоці
   - Показує статус виконання

```bash

```

## Сценарій використання:

1. Запустити програму → з'явиться вікно
2. Натиснути **"Вибрати файл нарахувань (ODS)"** → вибрати ODS файл
3. Натиснути **"Вибрати файл виписок (XLSX)"** → вибрати XLSX файл  
4. Натиснути **"Вибрати місце для результатів"** → вказати де і як назвати результат
5. Натиснути **"Обробити файли"** → програма обробить дані
6. Дочекатися повідомлення про успіх

## Технічні деталі:

- **Фреймворк:** Fyne v2.5.0 (cross-platform GUI для Go)
- **Окремі потоки:** Обробка запускається в горутині для чутливості UI
- **Діалоги:** Використовуються стандартні системні діалоги
- **Статус:** Показується прогрес обробки в реальному часі
